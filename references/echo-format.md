# Echo Format

Use one compact structured reply.

## Mission
One sentence describing what the user is actually trying to achieve.

## Locked
- Confirmed decision or constraint.
- Confirmed priority.

## Open
- Unanswered question.
- Unresolved choice.

## Ledger
- Flip: earlier position → later adopted position.
- Parked tangent: item retained for later.

## My additions
- Inferred: strongly implied but not stated.
- Guessed: model-filled gap.

Close by inviting corrections and offering the interview.

For the Wondering Aloud extension, after Echo approval:
- Original Response follows the approved Echo normally.
- Clarified Response may use only Open/My additions to generate targeted
  questions and incorporate the user's answers.
